# Kaplan-Meier Survival Curve Prompt

Use the dataset produced by `notebooks/create_itsm_survival_pipeline.ipynb` as the modeling input. The data should include `assignment_group`, `survival_event`, and `duration_days` for ITSM incident tickets.

1. Discover the modeling API with `kmds_modeling.get_package_info()`.
2. Identify the modeling spec discovery method from the package metadata. Use `kmds_modeling.get_spec_questions()` if that is the supported interface.
3. Set the modeling task to `KAPLAN_MEIER`.
4. Build a survival model spec that uses the Kaplan-Meier task and includes the required fields from `get_spec_questions()`.
5. Generate Kaplan-Meier survival curves for the support groups with the most resolved tickets, plotting the top 3 groups by count.

Required outputs:
- A valid model spec or spec answer structure for the `KAPLAN_MEIER` task.
- Kaplan-Meier curves plotted for the top 3 support groups by ticket closure count.
- A concise description of the dataset source and the target variables used.

Constraints:
- Do not use `TABULAR_REGRESSION`.
- Use the survival dataset generated by `create_itsm_survival_pipeline.ipynb`.
- Use the kmds modeling package's official discovery helpers, not hard-coded assumptions when possible.
