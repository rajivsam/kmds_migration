# california_housing

This project follows the same Python workspace setup pattern as the sibling SBA migration example.

## Included

- Python project metadata via `pyproject.toml`
- uv-managed virtual environment with Python 3.13
- typed project layout for data, models, notebooks, and outputs
- dev dependency for Jupyter kernels (`ipykernel`)

## Typical workflow

1. Edit project configuration in `config.yaml`.
2. Add project data in `data/` and `data_dictionary/`.
3. Develop models or pipelines under `models/` or notebooks.
4. Write outputs to `output/`.
